= .svelte 文件
一个 .svelte 文件的核心功能可以总结为：它是构建 Svelte 应用的基本单元，将组件的逻辑、内容和样式整合在一个文件中，形成完整的、可复用的 UI 模块。

实际上就是一个项目组件。

= .svelte.js / .svelte.ts
除了具有普通的 js/ts 文件的功能外，还可以使用 svelte 的 runes 符文魔法。
