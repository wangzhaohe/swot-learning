== 创建新项目
https://nuxt.com/docs/4.x/getting-started/installation

Prepare Directory

    mkdir -p nuxt/nuxt4
    cd nuxt/nuxt4
    pnpm create nuxt@latest nuxt4-basic

.下载模板直接使用项目
****
如果您在执行命令 `pnpm create nuxt@latest nuxt4-basic` 时报 raw.github.com 超时或者无法访问，可以去 gitee.com 上下载一个已经生成的模板项目。

下载后进入模板项目后，执行 pnpm install 即可。
