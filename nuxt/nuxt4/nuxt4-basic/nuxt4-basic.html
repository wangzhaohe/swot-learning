下载模板直接使用项目

如果您在执行命令 pnpm create nuxt@latest nuxt4-basic 时报 raw.github.com 超时或者无法访问，可以去 gitee.com 上下载一个已经生成的模板项目。

下载后进入模板项目后，执行 pnpm install 即可。

命令安装方式2 指定模板的安装方式

https://github.com/nuxt/starter

下载 nuxt3 模板

$ npx nuxi init -t v4 nuxt-app  // nuxt-app 是自己起的项目名称

  1. cd nuxt-app 安装相应的包

    $ pnpm install

  2. 启动开发服务器

    $ pnpm run dev

命令安装方式3 集成到现有项目

进入现有项目：

cd 项目

初始化 package.json

npm init -y

安装 nuxt

npm install nuxt

创建 nuxt.config.ts

import { defineNuxtConfig } from "nuxt/config"
export default defineNuxtConfig({})

创建 tsconfig.json

{
    "extends": "./.nuxt/tsconfig.json"
}

添加启动开发命令 - 编辑 package.json

"scripts": {
    "dev": "nuxi dev",
},

启动项目

npm run dev
启动项目后会自动生成 "./.nuxt/tsconfig.json"

手工创建 app.vue

<template>
    <h1>Hello World!</h1>
</template>

8. 配置路由 pages

更改 app.vue 文件
<template>
<div>
    <NuxtPage />
</div>
</template>
创建目录 pages
mkdir pages

单文件路由

  1. 创建 app/pages/index.vue，会作为根路由 → /

    <template>
<div>
    index pages
</div>
</template>

  2. 创建其它路由 app/pages/about.vue → /about

    <template>
    <div>
        about pages
    </div>
</template>

子目录路由

  1. 路由：/example1

    mkdir example1
touch example1/index.vue
    example1/index.vue
    <template>
<div>
    I am Example1
</div>
</template>

  2. 路由：/example1/sub-page

    touch example1/sub-page.vue
    example1/sub-page.vue
    <template>
<div>
    I am example1/sub-page
</div>
</template>
子目录可以嵌套多层，实际开发中不建议，因为太深了，不利于 SEO 时爬虫的爬取。
