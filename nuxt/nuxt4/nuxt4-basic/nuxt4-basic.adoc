=== 命令安装方式2 指定模板的安装方式
https://github.com/nuxt/starter

下载 nuxt3 模板

    $ npx nuxi init -t v4 nuxt-app  // nuxt-app 是自己起的项目名称

. cd nuxt-app 安装相应的包

    $ pnpm install

. 启动开发服务器

    $ pnpm run dev

=== 命令安装方式3 集成到现有项目
进入现有项目：

    cd 项目

初始化 package.json

    npm init -y

安装 nuxt

    npm install nuxt

创建 nuxt.config.ts

    import { defineNuxtConfig } from "nuxt/config"
    export default defineNuxtConfig({})

创建 tsconfig.json

    {
        "extends": "./.nuxt/tsconfig.json"
    }

添加启动开发命令 - 编辑 package.json

    "scripts": {
        "dev": "nuxi dev",
    },

启动项目

    npm run dev

NOTE: 启动项目后会自动生成 "./.nuxt/tsconfig.json"

手工创建 app.vue

    <template>
        <h1>Hello World!</h1>
    </template>

== 8. 配置路由 pages
.更改 app.vue 文件
[source,xml]
----
<template>
<div>
    <NuxtPage />
</div>
</template>
----

.创建目录 pages
[source,console]
----
mkdir pages
----

=== 单文件路由
[upperalpha]
. 创建 app/pages/index.vue，会作为根路由 -> /
+
[source,html]
----
<template>
<div>
    index pages
</div>
</template>
----

. 创建其它路由 app/pages/about.vue -> /about
+
[source,html]
----
<template>
    <div>
        about pages
    </div>
</template>
----

=== 子目录路由
[upperalpha]
. 路由：/example1
+
[source,console]
----
mkdir example1
touch example1/index.vue
----
+
.example1/index.vue
[source,html]
----
<template>
<div>
    I am Example1
</div>
</template>
----


. 路由：/example1/sub-page
+
[source,console]
----
touch example1/sub-page.vue
----
+
.example1/sub-page.vue
[source,html]
----
<template>
<div>
    I am example1/sub-page
</div>
</template>
----

NOTE: 子目录可以嵌套多层，实际开发中不建议，因为太深了，不利于 SEO 时爬虫的爬取。
